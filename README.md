# EDITOR OSCURO STUDIO

Editor de vídeo en el navegador, diseñado para trabajar localmente con tus archivos y publicarse como sitio estático en GitHub Pages.

## Estado inicial

Esta primera versión incorpora:
- Interfaz oscura adaptable.
- Importación de imágenes, GIF y clips de vídeo.
- Importación de narración de audio.
- Lectura de archivos TXT de escenas y subtítulos SRT.
- Vista previa básica y controles de reproducción de audio.
- Organización inicial de medios, audio y subtítulos en la línea de tiempo.
- Formatos de proyecto 16:9 y 9:16.

La exportación MP4, la sincronización avanzada por escena, los movimientos cinematográficos y la edición multipista completa todavía están pendientes de implementación y pruebas.

## Publicar con GitHub Pages

1. Abre **Settings** en el repositorio.
2. Entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save** y espera a que GitHub publique el sitio.

No requiere Python ni FFmpeg instalados en Windows.
